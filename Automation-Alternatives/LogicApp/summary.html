Approach 1 — Azure Logic App

Deployed as a Consumption Microsoft.Logic/workflows resource via ARM template (azuredeploy.json) — same convention as the repo's existing Logic Apps Module scenarios. The refresh token is passed as a securestring workflow parameter (encrypted at rest by the Logic Apps runtime) rather than a Key Vault reference, because this tenant's Azure Policy disables public network access on new Key Vault/Storage resources by default — blocking the SaaS Logic App from reaching them without private networking.
